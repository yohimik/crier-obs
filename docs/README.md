# crier-obs documentation

Start with [setup](setup.md). Then configure [triggers](triggers.md), the [data document](data-document.md), [credentials](secrets.md), [public staging](staging.md), or [custom platforms](custom-platforms.md).

[Advanced configuration](advanced.md) explains a base file and command line overrides. [Troubleshooting](troubleshooting.md) explains results and run folders. Contributors should read [development](development.md) and [releases](release.md).

The dialog mirrors crier v1.1.1. Its complete reference lives in [crier's configuration documentation](https://github.com/yohimik/crier/blob/v1.1.1/docs/configuration/README.md). These pages describe what the OBS client adds.
